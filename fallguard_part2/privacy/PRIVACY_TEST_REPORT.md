## Method and limits

- Leak test: for every frame the mock knows the true person box. A frame leaks if the output inside that box keeps at least 15% of the original neighbour-pixel detail.
- File audit: a Python audit hook records every write-mode `open()` and rename during the run.
- Limits: synthetic frames only, so this does not test face recognition by a human or model on real footage. OpenCV writes are not visible to the audit hook, but the code path only calls `imencode` and writes bytes through Python. Re-run this script on the demo machine and after any change to `blur.py`.
